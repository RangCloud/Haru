> 기준: 2026-10-07 코드(소비 분석·공휴일·뉴스 카테고리 반영) + 개인정보처리방침 v1.3 (https://claude.ai/artifact/Wtow7QzFfP4kb38yesbSKC)

## 판단 근거 (코드 확인 결과)

| 데이터 | 실제 흐름 | "수집"인가 |
|---|---|---|
| 위치 (위도·경도) | 날씨 조회 때 서버로 전송 → 기상청엔 5km 격자 번호만 전달. DB 저장 없음. **단, 서버 접속 기록(uvicorn·nginx 로그)에 요청 주소와 함께 최대 14일 남음** | **예** — 요청 처리 시간보다 오래 남기 때문 |
| 생년월일 (운세, 선택 입력) | 운세 요청 주소에 포함 → Claude API로 운세 생성. 당일 캐시 키로 메모리에 하루 보관. 접속 기록에 최대 14일 | **예** |
| 이름·이메일·프로필 사진 (Google/Apple 로그인) | Google/Apple → **기기 보안 저장소에만** 저장. 회사 서버 전송 없음 | 아니요 — 개발자가 접근할 수 없음 |

| 소비 분석 | 기기 안에서만 계산, 서버·AI 전송 없음 | 아니요 |
| 기기 캘린더 일정 (가져오기) | 사용자가 실행할 때만 폰의 캘린더를 읽어 기기 SQLite로 복사. 서버 전송 없음 | 아니요 — 캘린더 권한은 쓰지만 기기 밖으로 나가지 않으므로 "캘린더 일정" 유형은 체크하지 않는다 |

| 친구 기능 계정 | v1.0에서 탭이 숨겨져 사용 불가 | 아니요 (**v1.1에서 켤 때 반드시 두 설문 모두 갱신**) |
| 광고 ID·분석·크래시 SDK | 사용 안 함 | 아니요 |

## 🍎 App Store Connect → 앱 개인정보

**데이터 수집 여부**: `예, 이 앱에서 데이터를 수집합니다`

> 앱이 GPS 좌표를 소수점 그대로 보내므로 "대략적 위치"가 아니라 "정확한 위치"에 해당한다.

|---|---|

| 추적 목적으로 사용하나요? | **아니요** |

### ② 기타 데이터 → 기타 데이터 유형 (Other Data Types)
> 생년월일 — Apple 목록에 정확히 맞는 항목이 없어 "기타 데이터 유형"으로 신고한다.

| 질문 | 답 |
|---|---|

## 🤖 Google Play Console → 앱 콘텐츠 → 데이터 보안

### 개요 질문
| 질문 | 답 |
|---|---|
| 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** |
| 전송 중 데이터가 암호화되나요? | **예** (HTTPS) |
| 앱에서 지원하는 계정 생성 방법 | **OAuth** 만 체크 — 회사 서버에 계정은 없지만 첫 화면에 Google·Apple 로그인 버튼이 있어, "계정 생성 없음"으로 답하면 실제 화면과 달라 거절될 수 있다 (10/6 변경) |
| 계정 삭제 URL | https://claude.ai/artifact/BspFhWyr3TRYUw5K3njyEF — 지원 페이지의 "계정 및 데이터 삭제" 섹션 (**공개 설정 필수**) |
| 계정을 삭제하지 않고 데이터 삭제를 요청할 수 있나요? | **예** — 지원 페이지·개인정보처리방침의 이메일로 요청 |

### 데이터 유형별
**위치 → 정확한 위치**
| 질문 | 답 |
|---|---|
| 수집 / 공유 | **수집만** 체크 (공유 아님 — 기상청엔 좌표가 아닌 격자 번호만 가고, 이는 사용자가 요청한 날씨 조회를 위한 전달) |
| 일시적으로 처리되나요? | **아니요** (접속 기록에 최대 14일 남으므로) |
| 필수인가요, 선택인가요? | **선택** (권한 거부 시 서울 날씨로 계속 사용 가능) |
| 목적 | **앱 기능** |

**개인 정보 → 기타 정보** (생년월일)
| 질문 | 답 |
|---|---|
| 수집 / 공유 | **수집만** 체크 (Anthropic은 운세 생성을 대신 처리하는 서비스 제공업체라 '공유'에 해당하지 않음) |
| 일시적으로 처리되나요? | **아니요** |
| 필수인가요, 선택인가요? | **선택** (입력하지 않아도 운세 이용 가능) |
| 목적 | **앱 기능** |

### 그 외 유형 (이름, 이메일, 사용자 ID, 금융 정보, 앱 활동, 기기 ID 등)
- **선택하지 않음** — 기기에만 저장되는 데이터는 Play 기준으로도 '수집'이 아니다.
