## 공개 설정 (심사 전 필수)

두 페이지 모두 기본이 **비공개**라 로그인하지 않은 사람(심사자 포함)은 열 수 없다.

1. 각 주소를 열고 오른쪽 위 **공유(Share)** → **"링크가 있는 모든 사용자"** 선택
2. 브라우저 **시크릿 창**에서 두 주소가 로그인 없이 내용까지 보이는지 확인

## 이 주소를 쓰는 곳

주소를 바꾸면(페이지를 옮기면) 아래를 **모두** 함께 고친다. 한 곳이라도 다르면 심사 거절 사유가 될 수 있다.

| 위치 | 항목 |
|---|---|
| 앱 코드 `frontend/constants/links.ts` | `PRIVACY_POLICY_URL`, `SUPPORT_URL` (설정 → 앱 정보, 로그인 화면 링크). 바꾸면 새 빌드 필요 |
| App Store Connect → 앱 정보 | 개인정보 처리방침 URL |
| App Store Connect → 버전 페이지 | 지원 URL |
| Google Play Console → 앱 콘텐츠 | 개인정보처리방침 |
| Google Play Console → 앱 콘텐츠 → 데이터 보안 | 계정 삭제 URL (지원 페이지) |
| Google Play Console → 스토어 설정 | 웹사이트 (지원 페이지) |
| `store/01_스토어_설명문.md`, `store/02_개인정보_답안표.md` | 입력용 문구 |
