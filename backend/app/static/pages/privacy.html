하루(Haru) 앱

개인정보처리방침

시행일: 2026년 10월 29일 버전: 1.4
RangCloud(이하 "회사")는 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 방침은 하루(Haru) 앱(이하 "앱")에서 수집·이용하는 개인정보에 관한 사항을 안내합니다.

수집하는 개인정보 항목 및 수집 방법

가. 소셜 로그인 (선택사항)

로그인은 필수가 아니며, 로그인 없이도 앱의 모든 주요 기능(일정·가계부·날씨·운세·뉴스)을 이용할 수 있습니다.

로그인 수단수집 항목지원 플랫폼

기기에만 저장 소셜 로그인으로 수집된 정보(이름, 이메일, 프로필 사진)는 회사 서버로 전송되지 않으며, 이용자의 기기 보안 저장소(Secure Storage)에만 저장됩니다.

나. 소셜(친구) 기능 계정 (선택사항, 별도 가입)

친구 연결 및 일정 공유 기능을 이용하려면 앱 내에서 별도로 계정을 만들 수 있습니다. 이 계정은 위의 소셜 로그인과 별개입니다.

친구 요청·수락 내역, 이용자가 직접 공유한 일정(제목·날짜·메모)

다. 날씨 서비스 (위치 권한 허용 시)

현재 지역의 날씨를 보여 주기 위해 기기의 대략적인 위치를 사용합니다. 위치는 기기 안에서 기상청 단기예보의 약 5km 단위 격자 번호로 바뀐 뒤 사용되며, 위도·경도는 회사 서버로 전송하지 않습니다. 회사 서버에는 격자 번호만 전송되고, 이 번호는 기상청 날씨 조회에만 사용하며 별도의 데이터베이스에 저장하거나 이용자 계정과 연결하지 않습니다. 위치 권한은 앱 사용 중에만 사용되며, 권한을 거부하면 서울 기준 날씨가 표시됩니다.

서버 접속 기록 서버 보안 및 장애 대응을 위해 자동 생성되는 접속 기록(로그)에는 요청 주소와 함께 격자 번호가 남을 수 있습니다. 이 기록은 날씨 제공 외의 목적으로 이용하지 않으며, 최대 14일 보관 후 자동 삭제됩니다. 정식 출시 전 테스트 버전은 위도·경도를 전송했으며, 해당 기록도 같은 기준으로 최대 14일 후 자동 삭제됩니다.

라. 운세 서비스 (선택사항)

개인화 운세 생성을 위해 이용자가 직접 입력한 생년월일(년·월·일, 양력·음력, 선택적으로 태어난 시·분)을 회사 서버를 거쳐 Anthropic PBC(미국)의 AI 서비스 Claude로 전송합니다. 전송은 운세를 처음 이용할 때 앱 안 안내 창에서 이용자가 동의한 경우에만 이루어지며, 운세 기능을 이용하지 않으면 생년월일을 입력하지 않아도 됩니다. 이 정보는 운세 AI 생성에만 사용되며 회사는 별도의 데이터베이스에 저장하지 않습니다. 같은 날 같은 생년월일 요청에 동일한 운세를 제공하기 위해 서버 메모리에 당일까지만 보관하며, 이용자 개인과 연결되지 않습니다. 국외 이전에 관한 사항은 6번 항목을 참고해 주세요.

서버 접속 기록 운세 요청 시 생년월일은 요청 주소에 포함되므로, 날씨 서비스와 같이 서버 접속 기록(로그)에 남을 수 있으며 최대 14일 보관 후 자동 삭제됩니다.
운세 신고 운세 결과 화면에서 "부적절한 내용 신고"를 누르면 해당 운세 글과 날짜만 서버 접속 기록에 남습니다. 생년월일 등 이용자를 알아볼 수 있는 정보는 함께 전송하지 않으며, AI 답변 개선에만 사용하고 최대 14일 보관 후 자동 삭제됩니다.

마. 뉴스 서비스

뉴스 서비스 이용 시 개인정보를 수집하지 않습니다. 헤드라인·요약·기사 링크만 제공하며, 이용자 식별 정보는 전송되지 않습니다.

바. 기기에만 저장되는 정보

기기에만 저장 — 서버 전송 없음 아래 데이터는 이용자의 기기 내 로컬 데이터베이스(SQLite)에만 저장되며, 회사 서버나 외부로 전송되지 않습니다.
  • 가계부 거래 내역 (금액, 카테고리, 메모, 날짜)
  • 일정 내역 (제목, 날짜, 시각, 메모) — 기기 캘린더에서 가져온 일정 포함
  • 투두리스트 (항목명, 완료 여부, 날짜)
가계부의 소비 분석(기간별 합계·카테고리 비율·요약 문장)도 기기 안에서만 계산하며 서버나 외부 AI로 전송하지 않습니다.
앱을 삭제하면 위 데이터는 즉시 소멸됩니다.

사. 기기 캘린더 일정 가져오기 (선택사항, 캘린더 권한 허용 시)

설정의 "캘린더에서 일정 가져오기"를 이용자가 직접 실행한 경우에만, 기기의 캘린더(삼성 캘린더·Google 캘린더·iPhone 캘린더 등)에 저장된 일정의 제목·날짜·시각·메모를 읽어 앱의 일정으로 복사합니다. 이용자가 고른 캘린더와 기간의 일정만 읽습니다.

기기에만 저장 — 서버 전송 없음 읽어 온 일정은 기기 내 로컬 데이터베이스에만 복사되며 회사 서버나 외부로 전송되지 않습니다. 앱은 기기 캘린더의 일정을 수정하거나 삭제하지 않습니다. Android에서는 운영체제의 권한 구조상 캘린더 읽기·쓰기 권한이 함께 요청되지만, 앱은 읽기만 합니다. 캘린더 권한은 기기 설정에서 언제든 해제할 수 있으며, 해제해도 이미 복사한 일정은 앱에 남습니다.

이용자의 권리와 행사 방법

이용자는 언제든지 아래 권리를 행사할 수 있습니다.

  • 열람 — 수집된 개인정보 확인 요청
  • 정정·삭제 — 부정확하거나 불필요한 정보 수정 및 삭제 요청
  • 처리 정지 — 개인정보 처리 정지 요청
  • 동의 철회 — 앱 내 로그아웃 또는 탈퇴로 즉시 철회 가능, 운세 AI 전송 동의는 운세 화면의 "생년월일 다시 설정"으로 철회 가능, 위치·캘린더 권한은 기기 설정에서 언제든 해제 가능

소셜 기능 계정 삭제, 공유 일정 삭제 등 권리 행사는 아래 개인정보 보호책임자에게 이메일로 요청하실 수 있으며, 영업일 기준 3일 이내 처리합니다. 기기에 저장된 가계부·일정·투두 데이터는 앱 삭제 시 즉시 소멸됩니다. 삭제 방법은 고객 지원 — 계정 및 데이터 삭제에서도 확인할 수 있습니다.

개인정보의 안전성 확보 조치

  • 앱과 서버 간 모든 통신은 HTTPS(TLS)로 암호화
  • 소셜 로그인 토큰은 기기 보안 저장소(Secure Storage)에 보관, 외부에 노출되지 않음
  • 소셜 기능 계정 비밀번호는 암호화 후 저장
  • 가계부·일정·투두 데이터는 기기 내 SQLite에 저장되며 서버로 전송되지 않음
  • 위치는 기기 안에서 예보 격자 번호로 바꾼 뒤 전송하며, 위도·경도는 기기 밖으로 보내지 않음
  • 날씨·운세 조회 시 API 키는 서버에서만 관리하며 앱에 포함하지 않음
  • 서버 접속 기록은 관리자만 열람할 수 있으며 최대 14일 후 자동 삭제
