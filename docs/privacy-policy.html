하루 — 개인정보처리방침

시행일: 2025년 8월 19일

하루(Haru)는 가계부·일정·날씨·뉴스·운세를 하나로 모은 데일리 라이프 앱입니다. 가계부·일정 데이터는 기기에만 저장되며 외부 서버로 전송되지 않습니다. 본 방침은 「개인정보 보호법」 제30조에 따라 작성되었습니다.
1

수집하는 개인정보 항목 및 수집 방법

서비스 이용 방식에 따라 아래와 같이 개인정보를 수집합니다.

구분 수집 항목 수집 방법
소셜 로그인 이름(닉네임), 이메일 주소, 프로필 사진 URL Google / 카카오 / 네이버 OAuth 동의
날씨 현재 위치 (위도·경도) 기기 GPS (앱 사용 중에만, 서버 저장 없음)
가계부·일정 수입·지출 내역, 일정 제목·날짜 사용자 직접 입력 — 기기 내부에만 저장
※ 위치 정보는 날씨 조회 목적으로만 사용하며, 서버에 저장하거나 제3자에게 제공하지 않습니다.
※ 가계부·일정 데이터는 외부로 전송되지 않으며, 앱 삭제 시 완전히 삭제됩니다.
2

개인정보의 수집 및 이용 목적

  • 소셜 로그인 정보: 회원 식별, 닉네임·프로필 사진 표시
  • 위치 정보: 현재 위치 기반 날씨·기상 예보 제공
  • 가계부·일정 데이터: 앱 내 개인 재무·일정 관리 기능 제공 (기기 내부에서만 처리)
3

개인정보의 보유 및 이용 기간

항목보유 기간
소셜 로그인 정보 (이름, 이메일, 프로필 사진) 앱 내 로그인 세션 기간 동안 / 로그아웃 시 삭제
위치 정보 날씨 API 호출 즉시 사용 후 파기 (저장하지 않음)
가계부·일정 데이터 사용자가 직접 삭제하거나 앱을 삭제할 때까지 (기기 내부)
4

개인정보의 제3자 제공

하루는 원칙적으로 이용자의 개인정보를 제3자에게 제공하지 않습니다.

단, 아래의 경우에는 예외로 합니다.

  • 이용자의 사전 동의가 있는 경우
  • 법률의 특별한 규정이 있거나 법령상 의무 준수를 위해 불가피한 경우
5

개인정보처리 위탁

하루는 서비스 운영을 위해 아래와 같이 개인정보 처리 업무를 위탁합니다.

수탁업체위탁 업무보유 기간
Google LLC Google OAuth 소셜 로그인 인증 로그인 세션 기간
카카오(Kakao Corp.) 카카오 소셜 로그인 인증 로그인 세션 기간
네이버(NAVER Corp.) 네이버 소셜 로그인 인증 및 뉴스 데이터 제공 로그인 세션 기간
기상청(Korea Meteorological Administration) 날씨 데이터 조회 (위도·경도 전달) API 호출 즉시 파기
Anthropic, Inc. AI 기반 오늘의 운세 생성 API 호출 즉시 파기 (개인 식별 정보 미전달)
6

정보주체의 권리·의무 및 행사방법

이용자는 언제든지 아래 권리를 행사할 수 있습니다.

  • 개인정보 열람 요구
  • 오류 등이 있을 경우 정정 요구
  • 삭제 요구
  • 처리 정지 요구
권리 행사는 아래 개인정보보호책임자에게 이메일로 요청하시면 지체 없이 조치합니다.
7

개인정보의 안전성 확보 조치

하루는 개인정보의 안전성 확보를 위해 다음 조치를 취합니다.

  • 전송 구간 암호화: 앱↔서버 간 전 구간 HTTPS(TLS) 통신
  • 최소 수집 원칙: 서비스에 필요한 최소한의 정보만 수집
  • 로컬 우선 저장: 가계부·일정 데이터는 기기 내 SQLite에만 저장하며 외부 서버 전송 없음
  • 접근 제한: 소셜 로그인 토큰은 기기의 보안 저장소(Secure Store)에만 보관
  • API 키 보호: 외부 API 키는 서버 환경 변수에만 보관, 앱 코드에 미포함
8

개인정보 자동 수집 장치

하루는 쿠키(Cookie)를 사용하지 않습니다.

위치 정보는 날씨 기능 사용 시 이용자의 동의(앱 권한 허용)를 통해서만 수집하며, 권한을 거부해도 위치 기반 날씨 기능 외 나머지 기능은 정상 이용 가능합니다.

9

만 14세 미만 아동의 개인정보

하루는 만 14세 미만 아동의 개인정보를 수집하지 않습니다. 만 14세 미만인 경우 법정대리인의 동의가 필요하며, 확인된 경우 즉시 해당 정보를 삭제합니다.
